# Close Odontologia Igarapé LTDA

Landing page premium e funcional criada para a clínica.

## Como visualizar

1. Abra o terminal na pasta do projeto.
2. Execute:
   ```bash
   python3 -m http.server 8000
   ```
3. Acesse:
   ```text
   http://localhost:8000
   ```

## Funcionalidades
- Hero premium com identidade visual em branco, roxo e laranja.
- CTA para WhatsApp e ligação direta.
- Mini formulário funcional que abre mensagem no WhatsApp.
- Seção de serviços, avaliações, contato e mapa.
- Design responsivo para mobile e desktop.
